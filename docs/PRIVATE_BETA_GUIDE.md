# Laras Private Beta

Laras helps testers keep one career profile, prepare documents, track opportunities, and practise interviews and English.

This beta is for invited testers only. Use fictional or low-sensitivity data; do not upload passwords, identity numbers, confidential employer material, private messages, or API keys. AI output is a draft and must be checked before use.

Access is controlled server-side by `PRIVATE_BETA_MODE` and `PRIVATE_BETA_EMAILS`. Accounts may be reset during testing. Report problems using the guidance in `FEEDBACK_GUIDE.md`.

Known limitations are listed in `KNOWN_LIMITATIONS.md`; this is not a public-production release.
