   247→   247→## 4.2 Preserve the ZIP working tree
   248→   248→
   249→   249→If `.git` already exists:
   250→   250→
   251→   251→* Inspect the current branch.
   252→   252→* Inspect remotes.
   253→   253→* Preserve all current files.

   255→   255→
   256→   256→If `.git` does not exist:
   257→   257→
   258→   258→1. Clone the GitHub repository into a temporary directory using `--no-checkout`.
   259→   259→2. Copy only its `.git` metadata into the ZIP working directory.
   260→   260→3. Delete the temporary clone.
   261→   261→4. Do not copy source files from the remote.
   262→   262→5. Do not checkout anything that overwrites ZIP content.
   263→   263→
   264→   264→Conceptual safe sequence:
   265→   265→
   266→   266→```bash
   267→   267→REPO_URL="https://github.com/algojogacor/laras"
   268→   268→BRANCH="upgrade/laras-100x"
   269→   269→
   270→   270→if [ ! -d ".git" ]; then
   271→   271→  TEMP_DIR="$(mktemp -d)"
   272→   272→  git clone --no-checkout "$REPO_URL" "$TEMP_DIR/repo"
   273→   273→  cp -a "$TEMP_DIR/repo/.git" ./.git
   274→   274→  rm -rf "$TEMP_DIR"
   275→   275→fi
   276→   276→
   277→   277→git remote set-url origin "$REPO_URL"
   278→   278→git fetch origin main
   279→   279→```
   280→   280→
   281→   281→Branch selection:
   282→   282→
   283→   283→```bash
   284→   284→if git show-ref --verify --quiet "refs/heads/$BRANCH"; then
   285→   285→  git switch "$BRANCH"
   286→   286→elif git ls-remote --exit-code --heads origin "$BRANCH" >/dev/null 2>&1; then
   287→   287→  git switch --track -c "$BRANCH" "origin/$BRANCH"
   288→   288→else
   289→   289→  git switch -c "$BRANCH"
   290→   290→fi
   291→   291→```
   292→   292→
   293→   293→If Git warns that ZIP files will be overwritten, abort that operation and preserve the ZIP.
